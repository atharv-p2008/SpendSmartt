# Rupee Spending Insights

Build a complete, responsive student finance management web application called SpendSmart. Tagline: Take Control. Spend Smarter.\n\nDESIGN: Create a premium fintech dashboard with a dark navy sidebar, clean light main content, blue and teal accents, modern typography, rounded cards, subtle shadows, and professional charts. Make it responsive for desktop and mobile.\n\nFEATURES:\n1. Dashboard showing monthly budget, total expenses, remaining balance, savings, and recent transactions.\n2. Expense tracker with working Add, Edit, and Delete functionality. Each transaction should have an amount, description, category, date, and payment method.\n3. Categories: Food, Transport, Shopping, Education, Entertainment, Health, and Other.\n4. Analytics page with interactive charts showing category-wise spending and monthly spending trends.\n5. Budget manager allowing users to set a monthly budget and view spending progress. Show a warning when spending approaches or exceeds the budget.\n6. Savings goals page where users can create goals, set target amounts, and update saved amounts with progress bars.\n7. A Smart Insights section that generates useful spending observations from the actual transaction data using transparent rule-based logic. Do not pretend to use an AI API.\n\nFUNCTIONAL REQUIREMENTS: All buttons and navigation must work. Use Indian Rupees (₹) and realistic sample student transactions. Persist all changes using browser localStorage so data remains after refresh. Include a reset demo data option. Calculate all totals and charts dynamically from the transactions. Include empty states and form validation.\n\nIMPORTANT: Do not create fake buttons or nonfunctional features. Do not require paid APIs, authentication, or external banking connections. Keep the project easy to deploy on Vercel. Use clean, maintainable code.\n\nCreate the complete application, not just a landing page or static mockup. Prioritize functionality and visual polish.
